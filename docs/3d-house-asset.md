## 2 资产内容与版本

本资产由「数据 + 渲染 + 文档」三部分组成：

1. **数据层**：`src/3d-house-editor/main.js` 中的 `createDefaultPlan()`，唯一数据源。含 `meta`（版本、名称、备注）、22 段墙体（`walls`）、5 樘门（`doors`）、6 处窗/通口（`windows`）、11 块房间地面（`rooms`）、3 段阳台栏板（`rails`）、1 部楼梯（`stairs`）、**42 件家具（`furniture`）** 与楼板外轮廓多边形（`footprint`）。
2. **渲染层**：`index.html` / `style.css` / `main.js` / `editor.js` + `vendor/`（本地 Three.js 与 OrbitControls）。提供 3D 透视 / 2D 正投影顶视、线框/实体、降墙预览、属性面板、顶点拖拽与构件平移、增删构件、JSON 导入导出、方案保存与历史方案、**第一人称漫游（带碰撞）**。
3. **文档层**：`src/3d-house-editor/readme.md`（项目说明、构件清单、操作手册、接口说明）与本文件（归档资产说明）。

版本规则：`createDefaultPlan()` 中构件数量或坐标变化记为**数据版本升级**；仅界面/交互调整记为**界面版本升级**。当前版本 **v1.1**（v1.0 首次归档 → v1.1 增补家具与漫游），坐标与构件清单修改需在变更记录中留痕。

## 8 运维集成说明

### 8.1 Hermes 运维后台（8090）嵌入

```html
<iframe src="/3d-house-editor/index.html"
        style="width:100%;height:calc(100vh - 48px);border:0;border-radius:12px"
        allow="fullscreen"></iframe>
```

- 页面检测到 `window.parent !== window` 后自动加 `body.is-embedded`，收紧顶栏留白、隐藏副标题，适配嵌入视图；
- 全站零外链资源（Three.js 与 OrbitControls 本地化），内网离线可用；
- 建议静态托管路径：`D:\hermes\static\3d-house-editor\`（与当前目录结构保持一致）。

### 8.2 后端接口（预留，未就绪时自动降级 localStorage）

| 方法 | 路径 | 载荷 / 返回 |
|---|---|---|
| POST | `/api/house/plan/save` | `{ name, plan }` → `{ ok: true }` |
| GET | `/api/house/plan/list` | → `{ items: [{ name, at, plan }] }` |
| GET | `/api/house/plan/load?name=` | → `{ plan }` |
| POST | `/api/house/plan/delete` | `{ name }` |

### 8.3 DSH 侧边拾取桥接

iframe 内选中构件时向父窗口发送：

```js
{ source: 'dsh-3d-house-editor', type: 'select',
  payload: { id, kind, name, props, source: { file: 'src/3d-house-editor/main.js', anchor: 'id: "wall-master-south"', line } } }
```

父窗口下发 `{ source: 'dsh-host', type: 'select', id }` 可反向选中构件，实现"预览界面点选 → 下发修改指令"的闭环。

### 10.2 第一人称漫游与碰撞

| 项目 | 实现 |
|---|---|
| 进入方式 | 工具栏「漫游」按钮 / `HouseEditor.enterWalk()`；自动切回真实层高、关闭线框、补顶棚、隐藏编辑 UI |
| 移动 | `WASD` / 方向键，3.0 m/s，`Shift` ×1.9；视高 1.62 m，FOV 68° |
| 转身 | Pointer Lock 优先；iframe 未授权时自动降级「按住左键拖动」；`Esc` 退出 |
| 碰撞体 | `House3D.buildColliders(plan)` 生成 XZ 平面 OBB 共 70 个：墙体实心段 25 / 栏板 3 / 楼梯 1 / 家具 41 |
| 碰撞算法 | 相机水平位置视为 r = 0.30 m 的圆，逐帧与 OBB 做圆-矩形推挤，迭代 3 次收敛 |
| 洞口处理 | 门洞与通口处墙体本身无实心段 → 天然可通行；窗洞下方窗台墙仍为实心 → 不会穿窗 |
| 顶棚 | `ceiling` 按楼板轮廓生成，仅漫游时可见，避免室内上方露出背景色 |
